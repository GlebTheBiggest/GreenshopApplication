# Про проєкт

GreenshopApplication — бекенд для інтернет-магазину (Spring Boot 3.5, Java 21, Maven).

## Основні можливості

- JWT-аутентифікація з ролями (User / Manager / Admin)
- каталог товарів
- кошик
- замовлення
- профілі користувачів
- платежі через Stripe(криві)
- завантаження та отримання зображень
- PostgreSQL через Spring Data JPA
- Swagger (SpringDoc)
- надсилання електронної пошти
